Impacket NRPC API Reference Notes
=================================

Purpose
-------
Impacket is a Python library that implements several network protocols.

For this project, Impacket documentation is treated only as static
reference material.

No Impacket module is imported or executed by the RAG program.

Relevant Module
---------------
impacket.dcerpc.v5.nrpc

The nrpc module contains structures and functions related to the
Microsoft Netlogon Remote Protocol.

Example API Names
-----------------

NetrServerReqChallenge
Helper Function Signature
-------------------------

hNetrServerReqChallenge(
    dce,
    primaryName,
    computerName,
    clientChallenge
)

Purpose:
This helper constructs and sends the Netlogon challenge request.

Parameters:

dce
    An existing DCE/RPC connection object.

primaryName
    The primary server name parameter used by the NRPC call.

computerName
    The computer name associated with the request.

clientChallenge
    An 8-byte client challenge value.

Return:
    The helper returns the response object produced by the NRPC request.

Research Note:
This signature is included only as static API documentation.
The RAG system does not call this function.
Purpose:
Represents the Netlogon challenge request operation.

Conceptually, a client provides a challenge value and the server
returns its own challenge value.

Typical parameters include:

PrimaryName
ComputerName
ClientChallenge


NetrServerAuthenticate3

Purpose:
Represents a Netlogon authentication operation.

Conceptually, this API participates in establishing a secure channel
between a machine and a domain controller.

Important conceptual parameters may include:

PrimaryName
AccountName
SecureChannelType
ComputerName
ClientCredential
NegotiateFlags


NETLOGON_CREDENTIAL

Purpose:
Represents a Netlogon credential value used during authentication.

This structure contains credential bytes generated by the Netlogon
authentication process.


NETLOGON_AUTHENTICATOR

Purpose:
Represents an authenticator structure used by Netlogon operations.

It conceptually contains:

Credential
Timestamp


Secure Channel Types
--------------------

Examples of Netlogon secure channel types include machine-related
secure channels and domain-related secure channels.

For this project, secure channel values are studied only as protocol
metadata.


Static Analysis Policy
----------------------

This document exists so that the retrieval system can recognize
Netlogon API names and explain their purpose.

The project must not:

- import Impacket
- send RPC requests
- authenticate to a domain controller
- modify machine account information
- extract secrets
- execute generated attack code

The expected LLM behavior is to explain APIs, identify parameters,
compare protocol concepts, and produce non-executable research notes.
